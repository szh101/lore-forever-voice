# Lore Forever 中文女声旁白

为 WoW: Forever 插件 Lore Forever（CurseForge 1715510）录制的中文女声旁白。插件文字保持英文，剧情用中文朗读。
做成一位独立的旁白 "Lore Forever Chinese female narrator"（`LoreForever_Voice_ChineseFemale` 及其扩展包），不需要语言包。

- 安装（游戏电脑上的 Claude）：[INSTALL.md](INSTALL.md)
- 制作记录、哈希验证、没做完的部分：[REPORT.md](REPORT.md)
- 最初的制作说明：[INSTRUCTIONS.md](INSTRUCTIONS.md)（之后改为只要语音，见 REPORT.md）
- 成品包在 [Releases](../../releases) 里，每个插件文件夹一个 zip，附 `release-manifest.json`（含 sha256）。

剧情文字改编自 [Warcraft Wiki](https://warcraft.wiki.gg)，按 CC BY-SA 4.0 授权；中文旁白稿是它的翻译。
声音是仓库主人自己的 AI 声音，只授权用于这个插件的旁白。
Lore Forever 是粉丝制作的插件，与暴雪无关。World of Warcraft 是暴雪娱乐的商标。
